# Nimbus Cloud — Support Guide

Nimbus Cloud is a file-sync product for small teams.

## Accounts
Each workspace can have 25 seats on the Team plan. Extra seats cost $8 per month.

## Support
Email support@nimbus.example for billing, SSO, and outages.
Live chat is available Monday to Friday, 9:00–18:00 IST.

## Storage
The Team plan includes 2 TB shared storage. Files larger than 5 GB must use the desktop client.
